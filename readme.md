# Это простенький загрузчик видео и аудио с Ютуба

Загружает видео в максимальном качестве или 720р в формате .mp4

Так же есть возможность скачать только аудио в .mp3

Всё загружается в папки video и music (создаются автоматичеки там, где запущена программа)

Только нужен доступ к Ютубу. Его можно проверить в консоли ping youtube.com

В моем случае нужно поменять DNS в винде на 1.1.1.1 (или 8.8.8.8) и включить рабочую стратегию zapret'а

# Разработка

Написан на Python 3.12.7 и yt-dlp 2026.8.19

Нужно скачать и кинуть в папку проекта ffmpeg.exe и ffprobe.exe (в папке bin)

https://github.com/BtbN/FFmpeg-Builds/releases

Сборка в .exe при помощи Pyinstaller командой:

pyinstaller --onefile --console --add-binary "ffmpeg.exe;." --add-binary "ffprobe.exe;." main.py
